# Учебный frontend-проект (КР №1)

## Описание

Проект представляет собой многостраничный HTML/CSS-сайт интернет-магазина, разработанный в рамках дисциплины «Фронтенд и бэкенд разработка».

**Тема контрольной работы №1:** «HTML и CSS: разработка многостраничного сайта».

## Структура проекта

- `index.html` – главная страница;
- `catalog.html` – каталог товаров с фильтрами;
- `product.html` – страница карточки товара с таблицей характеристик;
- `order.html` – страница оформления заявки;
- `contacts.html` – контактная информация;
- `css/style.css` – файл стилей;
- `js/main.js` – файл JavaScript (логика модального окна);
- `images/` – папка для изображений;
- `README.md` – описание проекта.

## Используемые технологии и особенности

- **HTML5** (семантическая разметка: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`).
- **CSS3** (внешний файл стилей).
- **Flexbox** (для навигации и внутренней структуры карточек).
- **CSS Grid** (для сетки товаров и макета каталога).
- **БЭМ** (именование классов по методологии Блок__Элемент--Модификатор).
- **CSS-переменные** (в `:root` для цветов, отступов и скруглений).
- **Состояния** (`:hover`, `:focus-visible`, `:disabled`).
- **Позиционирование** (`position: relative` для карточек, `position: absolute` для бейджей «Скидка»/«Хит»).
- **JavaScript** (минимальный скрипт для открытия/закрытия модального окна на главной странице).

## Позиционирование

В проекте реализовано базовое позиционирование:
- `position: relative` используется для карточек товаров (`.product-card`);
- `position: absolute` используется для бейджей (`.product-card__badge`);
- `z-index` применён для бейджа, чтобы он был поверх других элементов.
